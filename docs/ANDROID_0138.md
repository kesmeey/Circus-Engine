# Android 0.13.8：DC3R 原版存档导入与演出修复

安装 `build/distribution/circus-runtime-0.13.8-android-dev.apk`，可以覆盖安装。解释器已有的游戏目录、设置和存档继续保留；不需要卸载应用。

## 导入 DC3R 的 PC 存档

1. 在电脑打开 `%APPDATA%\Mangagamer\DaCapo3R`。本机对应 `C:\Users\Administrator\AppData\Roaming\Mangagamer\DaCapo3R`，与游戏目录分开。
2. 把其中的 `global.dat` 和 `save000.dat` 至 `save101.dat` 复制到手机上的一个文件夹。
3. 在启动器的 DC3R 游戏卡片选择「更多 → 导入原版存档 → 选择存档文件夹」。存档已放在游戏目录里时，也可以选择「在游戏目录中查找」。
4. 查看新增进度、可转换槽位、同号冲突及不支持的文件。默认保留手机同号存档；选择「备份并替换同号存档」才会替换，并先备份旧文件。
5. 启动游戏，在原版 LOAD 界面读取。`save101.dat` 对应自动存档。

`global.dat` 合并增加已验证的通关、CG 和场景标记，保留手机设置与已有进度。剧情槽位转换脚本位置、局部变量和栈、图层、场景设置与循环音频；使用原版 START 初始化消息窗口定义，随后恢复原档位置，不通过重新推进剧情猜测进度。原版文件全程只读。替换前的手机文件保存在该游戏私有存档目录的 `before-native-import-*` 子目录。

支持范围是本机已验证的 DC3R Unity 5.5 版本，检查 START 与鉴赏表版本。不同版本、损坏文件或含尚不支持的状态会明确报告，不生成假成功槽位。当前不支持带部分挂起系统等待、动作／动画包对象、特殊持久绘图对象等状态的原档；导入预览按文件列出结果。尚未验证全路线的每一种原存档。

原版已读文本记录的编号不同于脚本行号，本版不导入这部分记录。原版快速存档只存在于 PC 进程内存中，没有可复制的磁盘文件。循环音频按原版读档行为从头播放，原档没有音频游标。

此前 DCPC、DC2PC、DC2DM、DC3DD 的原版系统进度导入继续保留；这四个 MES 版本的原版剧情槽位不在本次转换范围内。

## DC2PC 大尺寸立绘

修复 Dacapo 线 `1ind_0119_e1_skr` 中音姬背影与樱的构图错误。脚本本来就同时显示两个人物；原实现未按原引擎的 882×756 基准定位 1260×1080 的近景，且绘制槽位顺序相反。现在按原生绘制函数的整数公式定位并依槽 0→3 绘制，仅作用于 `dc2pc-5769`。旧解释器存档无需迁移。

原生地址、公式、真实场景与回归证据见 [DC2PC 立绘定位](DC2PC_ACTOR_LAYOUT.md)。

## DC3R 序章背景动画

姬乃出场这段同时使用平移的 `bg/railback`、滚动的 `system/rail_chip2` 和人物立绘。真实资源计数表明稳态没有反复加载纹理；此前每帧却新建一个 1024×576 的输出位图，单帧像素约 2.25 MiB。

Android 现在只对这一尺寸复用已经释放的帧缓冲，最多保留两张空闲位图（4.5 MiB）。每个返回的帧仍独立拥有其像素；正在显示或尚未释放的帧不会被下一帧复用。复用前清空，旧包装对象重复释放也不会破坏新帧。没有提高应用堆上限或扩大资源纹理缓存。

Android 35 模拟器以真实序章第五句为场景，同一 APK 开关复用各运行两轮、每轮 240 帧：

| 指标 | 关闭复用 | 开启复用 |
| --- | ---: | ---: |
| 平均构帧耗时 | 2.56 / 2.57 ms | 1.70 / 1.47 ms |
| P95 构帧耗时 | 4.26 / 4.42 ms | 2.78 / 2.18 ms |
| 新建视口位图数 | 240 / 240 | 0 / 0 |
| 垃圾回收次数 | 5 / 5 | 0 / 0 |

两轮共六个时间点的画面像素校验相同，20 项帧所有权、清空、容量、真实动画检查通过。这是确定性时钟下的软件 Canvas 构帧对照，不是用户手机的屏幕帧率；仍需在同一手机、同一段演出复测。证据：`build/dc3r-render-before/android-frame-audit.txt`。

## 验证边界

原存档验证使用本机真实 `save101.dat`，检查导入后从原 LOAD 恢复、继续对白、再次存读档、原文件不变。该机 `global.dat` 没有已解锁 CG／场景，因此另用自编 protobuf 标记和原版目录表验证正向解锁、持久化、幂等合并及保留手机设置。

本地原游戏资源和原档测试副本不进入 GitHub 或 APK。音视频完成回调用于无界面流程测试时有明确模拟标记；这类检查不代表手机音频实际播放或全部路线兼容。

最终 APK 通过 976 项 JVM／Android ART 核心断言、7 项 Canvas 像素契约、484 项遮罩像素比较。DC3R 原存档转换的桌面审计通过 42 项检查；Android 实际导入服务通过 23 项检查，包括真实原档 LOAD、继续和再存档，同号保留／备份替换、损坏输入、预览后来源变化、进度幂等及原文件哈希不变。实际 Android Activity 从标题进入序章并推进五句对白，使用真实帧时钟和 MediaPlayer，也通过检查。

DC2PC Android 实际 Activity 另通过 25 项检查，覆盖启动、12 次对白推进、存读档像素、快进时打开菜单／回看、原版存档界面和音频启动。
