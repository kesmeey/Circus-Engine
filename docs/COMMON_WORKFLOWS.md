# 常见流程交付范围

当前按用户指定的约80%目标推进，优先主要功能和常见游戏流程。下表描述实际检查范围，供选择游戏与复查使用；运行时入口、整条路线和原生逐帧等价分别记录。

| 游戏 | 当前源码检查 | 主要剩余限制 |
| --- | --- | --- |
| DCPC | 实际启动20次文本等待；原生文本、脚本、UI、背景、双角色、音频执行链及便携快照检查 | 原版剧情槽位依赖完整重建，自动槽写入仍可能阻断后续剧情；不是整作可玩验收 |
| DC2（2006） | 实际启动20次等待，初始粒子与便携快照回归 | 原生地图system20等仍未实现 |
| DC2PC | 实际启动；192MiB下首/末策略5,496/5,115句后回标题 | 只覆盖这些策略，不代表全部结局和系统组合 |
| DC2DM | 实际启动；192MiB下首/末策略37,741/37,663句后回标题 | 所有分支组合与原版实时媒体尚未穷举 |
| DC3DD | 实际启动；192MiB下首/末策略3,352/3,354句后回标题 | 本次两策略不代替此前七路线的重新全验；特殊嵌套UI等仍有限制 |
| DC3WY | 实际启动；修正版本专属片尾后，192MiB下代表策略推进2,737句、29脚本并回标题；九组片尾资源与条带像素检查 | 片尾末尾输入、逐帧淡出及部分镜头时钟使用已声明的兼容近似 |
| DC3PP | 实际启动；修正好感度计算和BGM完成查询后，首/末策略推进到第4章及MED | scene.effect4和system210阻断这些策略，尚无完整路线通过 |

长路线检查使用原始脚本、图片和资源，原EXE只读、不执行。选择策略、时间和媒体结束通知由审计控制；这些结果主要验证流程、资源和内存，实际音视频输出及原生时序另有各自范围。

剧情、分支变量、常见画面和转场、BGM/SE/语音、菜单、便携存读档、回看与鉴赏是本版的主要功能范围。PC1原生服务图仍与现有便携播放器并存，尚未整体替换WinMain/WndProc；原Windows槽位互通、少数版本和罕见平台状态可按当前目标延期。不能运行的版本继续明确拒绝。
