# Android 0.13.6：选择文字可读性与四版本启动优化

安装 `build/distribution/circus-runtime-0.13.6-android-dev.apk`，可以覆盖安装；保留游戏列表、解释器存档和原版系统进度导入功能。

## 选择文字

DC2PC 的 START 脚本给普通状态的按钮文字指定状态 9。PC 宿主此前只转换了图片按钮的这个状态，没有转换文字，导致选择条存在但不点中时看不到选项。
现在文字采用同样的常态显示规则，保留原版位置、悬停和按下效果。原版分支及跳转标签不变。

读取旧解释器快照时，同时转换当前菜单和已保存的 START 选择模板，因此在旧存档上继续推进也会生效。此前已经烘焙成图片的回看截图无法补回原来遗漏的文字。
状态 9 的转换限定于 `dc2pc-5769`；DCPC、DC2DM、DC3DD 原版选择文字已使用常态 99，不套用 PC2 状态解释。

另外补回 DCPC、DC2PC、DC2DM 原版文字样式 `0x80` 指定的一像素右下阴影，解决浅色画面上白字难以辨认的问题。保留前景颜色和原版布局；不增加八方向描边。
PC1／DM 阴影使用调色板 0；PC2 在前景索引为 0 时改用调色板 9。这些细节由各自原生字形绘制路径确认。
DC3DD 使用另一套绘制逻辑，已有文字效果；其 START 的三种选择状态使用相同文字样式，本次没有改动 DD 文字绘制。
四版均补齐已核对的原生默认调色板，包含白色前景、黑色阴影及默认强调色；DC2DM 的第 11 项与其他版本不同，按自身数据保留。
旧快照仅在前 13 项全部呈现旧实现的未初始化状态时迁移（PC／DM 全白，DD 全零），不覆盖已经自定义的调色板，也保留 START 设置的第 13 项及后续颜色。

静态证据来自原版 PC2：文字追加函数 `0x412860` 保存状态 9，普通显示设置 `0x4132E3` 将其设为可见。未使用旧源码目录。
PC2 阴影分支在 `0x421CA6`，默认调色板在 `0x500F30`；PC1 对应按钮文字阴影在 `0x417A5E`、默认表在 `0x4304F8`；DM 绘制链 `0x4206FF → 0x426910 → 0x425BF0 → 0x402030`。
DM、DD 默认调色板分别为 `0x4907B8`、`0x4AA108`，各自原 EXE 与当前汉化／免盘 EXE 的对应表一致。
本地 al fine 两处选择可复现：`ind_0401_a1_cmn @0x5BB`、`ind_0401_a1_cmn2 @0xEDA`，均为两项选择。

## 启动读取

优化的是启动器选择「启动」到出现游戏画面这一段。原脚本内的等待、影片和演出时长不变。

- 首次识别版本仍检查整套 MES；使用一个句柄读取每个脚本的头部及版本标记，不再完整读取正文。
- DC2PC 的 1,557 个脚本，版本识别读取量由 23,534,174 字节降为 21,798 字节。
- Android 每次重新枚举目录，使用 MES 路径、文档 URI、长度、修改时间生成指纹。清单未变化时复用已完成的版本检查，并重新读取 START 头部复核。
- 脚本新增、删除、大小或修改时间变化，会重新进行全套检查。文件提供器缺少有效元数据、缓存损坏或 START 不一致时，回退完整检查。
- 缓存位于应用私有缓存目录，丢失只会重新检查，不影响存档；选择目录后的配置检查也会建立缓存。

时间戳是新鲜度提示，并非内容认证。若非 START 文件被替换而文档 URI、大小、修改时间全部保持不变，此缓存无法察觉；脚本加载时仍经过原有解析验证。缓存格式或识别规则变化时需升级缓存目录版本。

最终 APK：JVM／Android ART 核心 **867** 项断言通过；Android Canvas **7** 项、转场遮罩 **484** 项像素比较通过，Python **47** 项通过。
四版原版标题、各 12 次正文推进、存档像素恢复、回看、菜单／保存网格和实际音频启动，共 **98** 项通过（DD 21、DM 25、PC1 27、PC2 25）。
PC2 两处原始 al fine 选择在桌面和 Android 均通过 **57** 项检查，包含普通／悬停／按下文字、浅色背景阴影、旧快照恢复及两项原始跳转。
PC1／PC2／DM 另用原始 START 模板搭配测试文字与白色底图，桌面和 Android 均各通过 **14** 项检查，共 **42** 项；测试文本不改写原游戏脚本。
缓存异常、目录元数据变化、START 歧义、缓存写入失败等 **25** 项 Android 合成检查通过。

验证记录位于本地 `build/choice-startup-0136/` 和 `build/android/verification-0136/`；不打包游戏数据。
Android 测试使用专用模拟器及隔离存档目录，没有操作实体手机。
本次验证聚焦选择文字、已有快照迁移、缓存失效及原版启动回归，不表示全路线已经重新验收。

Android 35 模拟器、DC2PC 全部 1,557 份 MES（其它资源为测试子集）的一次测量：

首屏计时包含 Activity 初始化、目录枚举和呈现，首次到再次的比较来自同一模拟器的一次连续运行，不是实体手机帧率或普遍性能保证。
