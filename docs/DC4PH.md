# D.C.4 Plus Harmony

0.14.14-dc4ph-dev 新增 `dc4ph-abb6` 独立运行时。核验对象为用户提供的 Plus Harmony 下载版目录，不能据此推断 D.C.4、Fortunate Departures 或其他补丁版兼容。

原 Windows EXE 只读、不执行。已破解启动器保留原样；原生合同来自同目录 `未破解原版.zip` 内静态提取的 995,328 字节引擎，SHA-256 为 `178ee9a5e34356b11942213e2e32a34afe4933c90d563bf5a3d6402250f54ab7`。没有宣称解出了外层破解启动器的全部代码，证据见[原生合同](validation/dc4ph-native-contract-2026-11-11.json)。

536 份实际 MES 均检查了 ABB6 取指边界和头部目标；资源抽样解码覆盖 2,466 张独立图片/容器帧、242 份音频。完整 CRXD 引用图检查覆盖 10,770 条差分链。这些检查验证格式和素材定位，不能代替剧情和设备播放。

新增逻辑包括原版 1280×720 画布、版本专属资源槽、背景居中/缩放和角色定位、相机长时钟、粒子、有限摆动、文字宏的录制/定时回放、COMU 文字、语音声像、PCK 帧动画、模糊、片尾、设置与音乐目录。菜单沿用原 MES，便携存档保存执行位置、变量和各个新增 owner 的时钟。旧版本的线格式和执行规则保持各自分支。

原菜单首选项策略已经由 START 连续推进 11,529 次稳定正文等待、115 份脚本，经 `ED_HIY` 和后续剧情返回标题；末选项策略在密码题选择原有正确项后，11,522 次等待、128 份脚本经 `ED_SOR` 返回标题，未改好感或通关变量。两条长流程使用与 APK 相同的核心及 DesktopDd 源码。

序章首选项策略另有 3,912 次等待、35 份脚本后返回标题的记录；该全程记录早于最终文本窗修正，最终源码另重验序章前20次等待及冷恢复。计数是审计观察到的稳定等待，不是剧本总句数，也不代表全部路线。时间与媒体完成在流程审计中受控；原菜单存读档、回看、设置和隔离音乐菜单另行检查。完整证据见[源码与交付验证](validation/dc4ph-source-2026-11-11.json)。

请完整复制游戏目录到手机，选择包含 `AdvData` 的那一层，文字编码用**自动或日文**。本份数据正文为 CP932；不要为此改动已有 SC/TY 汉化游戏的编码。原始游戏资源不会打进安装包。

当前明确保留的边界：

- 首次 Win32 改名表单采用原默认姓名“常坂 一登”；尚未提供可编辑表单。
- 日文注音/强调点控制已解析，正文正确显示；小号注音文字暂未绘制，注音数据会随快照保存。
- 原 Windows 剧情槽和本作 `system.dat` 全 CG 进度导入未实现；运行时自己的原菜单便携存读档另行验证。
- 部分遮罩/复合角色运动、COMU 贴图布局、回看头像预览、低倍率相机覆盖规则、片尾伴随背景与输入跳过使用近似或延期。
- 模糊使用便携合成图采样，区别于原 GPU 逐对象着色；8/40 转场保留停止角色运动和发布语义，但发布时间是兼容近似。
- 原语音暂停/恢复保留资源与播放意图，恢复会从头重播；不声称恢复原 DirectSound 物理游标。
- 八份 `ED_*.mes` 的 `99:250` 等待 BGM 结束查询按实际音频播放/完成回调实现。其含义依据脚本轮询推断；静态提取引擎的 getter 未找到相应分支，样本版本差异尚未查明，不能称为原生等价证明。
- 联网登记采用原生不发送的离线路径，不产生虚构登记成功标记。
