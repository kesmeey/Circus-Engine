长路线检查使用原始脚本、图片和资源，原EXE只读、不执行。选择策略、时间和媒体结束通知由审计控制；这些结果主要验证流程、资源和内存，实际音视频输出及原生时序另有各自范围。

剧情、分支变量、常见画面和转场、BGM/SE/语音、菜单、便携存读档、回看与鉴赏是本版的主要功能范围。PC1原生服务图仍与现有便携播放器并存，尚未整体替换WinMain/WndProc；DC2桌面可转换48个原读取菜单可见位置的普通ADV原Windows槽；其他家族原剧情槽互通、少数版本和罕见平台状态按当前目标延期。不能运行的版本继续明确拒绝。

FL旧2028系统进度按独立offset合并，现代2032布局保留；本次实际旧档源含597项CG、360项场景已读及16项通关标记，不将这些输入数量当成所有可用索引的容量。SC手机实际缺少必需资源编号索引 `AdvData/DAT/names.dat`，已补齐匹配文件；SAF按列名读取元数据是另一个经真实provider正负检查的鲁棒性修正，不是这次实机缺文件的原因。SC代表路线与DCDX长流程的未完成边界保持上表所列范围，详见[本轮统一验证](validation/ty-sc-fl-source-2026-11-08.json)。
