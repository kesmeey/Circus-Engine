# D.C.4 PH 原版进度导入

Android **0.14.15-dc4ph-progress-dev** 支持导入 D.C.4 Plus Harmony ABB6 的原版 `system.dat`，可用于合并全 CG 存档中的解锁记录。游戏卡片选择「更多 → 导入原版进度（选文件）」，选中解压后的 `system.dat`；也可用「从游戏目录查找原版进度」。导入后重新启动游戏查看原鉴赏菜单。

这版原文件精确为 **21,368 字节**：原生读写分别处理 `0x4B80` 主表和 `0x7F8` 声音设置尾部。它没有可验证的游戏版本标记；运行时先根据游戏的 START/MES 确认 PH 版本，再按独立布局解析。请选择来自本作的文件，剧情槽、压缩包和其他版本文件不能代替它。

| 合并内容 | 原文件布局 | 规则 |
| --- | --- | --- |
| CG 标记 | `0x310` 起，1200 字节 | 原菜单按 `==1` 判断，源值要求 0/1 |
| 场景标记 | `0x7C0` 起，650 字节 | 原菜单读取无符号字节，所有非零源值合并为已读 |
| 音乐标记 | `0x180` 起，400 字节 | 合并源档已有的 0/1 解锁记录 |
| 已确认的通关/鉴赏门槛 | `0xD8 + 100..112`，13 项 | 仅合并经原脚本和原生写入确认的布尔标记 |

上述是文件内标记容量，不是实际 CG 或歌曲数量。实际原菜单使用 960 个 CG 索引、493 个场景索引，Music Mode 列表有43项，音乐入口另依赖源档中的已确认门槛。

只增加源档已有的解锁记录，保留手机已有非零进度、设置、姓名、收藏、声音选项及剧情槽。导入前备份已有手机系统进度；重复导入相同内容不会再改写或重复备份。序章计数器120、分支状态121、其他未确认的全局变量、原Windows剧情槽及逐行已读文本不导入。遇到错误长度、异常CG/音乐/通关值或导入前已改变的文件会明确拒绝。

本地提供的 `Advdata/SAVEDATA/system.dat`（SHA-256 `47101ee4b3f47474ac3dc22716812ad6bbc4ff145b2eb4c2efdcf1dd5291a2ea`）没有 CG 和场景解锁记录，只有1项音乐标记，**它本身不是全 CG 档**。实际导入数量取决于所选源文件；空进度源不会产生全解锁效果。

验证使用上述原样本，以及只在 F 盘私有副本中设置已确认进度字段的合成全解锁样本。后者通过原菜单打开 CG、查看原图、翻页、场景回想和音乐模式；不能把该合成样本称为用户提供的真实全 CG 档。原Windows EXE未运行，原游戏和存档未修改，私有游戏数据不进入仓库或 APK。

本轮 JVM 与 Android ART 核心回归各通过1,150,211项检查；安卓真实 Content URI 导入与原CG查看通过52项检查。桌面正对照验证导入后可打开CG/翻页/场景及音乐菜单；空进度负对照不暴露CG0，点击相同位置也不会进入原图。实际范围见[同源交付验证](validation/dc4ph-progress-source-2026-11-11.json)及[APK与安卓验证](validation/android-dc4ph-progress-0.14.15.json)。

原生布局与字段依据见[原生合同](validation/dc4ph-progress-native-2026-11-11.json)和[样本及原菜单门槛](validation/dc4ph-progress-sample-gates-2026-11-11.json)。所有新构建、缓存、夹具和分发包位于 `F:\circus-runtime-work\dc4ph-progress-20261111`。
