# Android 0.13.9：直接选择原版进度文件

安装 `build/distribution/circus-runtime-0.13.9-android-dev.apk`，可覆盖安装。

## 使用

在游戏卡片选择「更多 → 导入原版进度（选文件）」，点选手机上的原版系统进度文件即可。启动器自动校验、转换并写入该游戏的手机进度，随后显示结果；无需选择文件夹、维持 PC 目录结构或再进入导入预览。

- DCPC、DC2PC、DC2DM、DC3DD：选择对应版本的 `system.dat`。
- DC3R／DC3XR Unity：选择 `global.dat`。

文件可以放在 Android 文件选择器能够访问的位置，也可以改名为 `system.data` 等名称；内容必须仍是当前游戏支持的原版系统进度格式。改名不会转换格式，选择错游戏、剧情槽位或损坏文件会报错并保留手机进度。

系统进度依旧采用已验证的合并规则：增加通关、CG、场景等解锁，保留手机设置、已有解锁和剧情存档；写入前备份已有手机进度，写入采用原子替换。所选原版文件只读，启动器不向外部文件申请写权限。

DC3R 的 `save000.dat` 至 `save101.dat` 剧情槽位仍使用第二项「批量导入原版存档（文件夹）」，沿用 0.13.8 的转换、冲突保留和备份替换规则。MES 版本第二项保留从游戏目录自动查找进度的入口。

## 实现与边界

文件选择器使用 `ACTION_OPEN_DOCUMENT`、`CATEGORY_OPENABLE` 和通用文件类型，因此不因扩展名或存放位置排除文件。选中文档以 ContentResolver 只读访问，不获取其父目录，不扫描邻近文件。选择器取消时不会开始导入。读取有大小上限，应用前再次校验来源内容，避免预览／校验后原文件变化。

这次简化的是操作入口，格式兼容范围延续 [0.13.8](ANDROID_0138.md) 与 [0.13.5](ANDROID_0135.md)。PC 原档与解释器内部保存格式不同，因此不能把原始字节直接覆盖到手机 `progress.dat`；转换由启动器自动处理。

## 验证

Android 35 模拟器使用实际 ContentResolver 文档读取，五个版本各通过 25 项检查，共 125 项。自编原格式进度样本放在额外测试目录中，分别使用 `.system.data` 与 `.unusual` 文件名，验证不依赖原名、扩展名或原版存档位置。检查包含正确解锁、备份字节一致、手机设置与剧情槽位不变、重复导入不写入、截断／超大／错误版本文件拒绝、来源内容变化及损坏目标保护。

最终 APK 还通过 976 项 JVM／Android ART 核心断言、7 项 Canvas 像素契约与 484 项遮罩比较。测试写入隔离目录，原版游戏和 PC 存档保持只读。报告位于 `build/single-file-import-0139/`，测试资源不随 APK 或源码包分发。

实际启动器也已验证：点选单文件入口直接打开 Android 文档选择器，返回取消后回到启动器，原有手机存档文件列表及 SHA-256 均不变。
